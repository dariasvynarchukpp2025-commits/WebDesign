# WebDesign

Лендинг клінінгової служби Tidyly (лабораторні роботи №7 та №9).

## Технології

- HTML5
- CSS3 / Tailwind CSS
- JavaScript (Vanilla JS)

## Лабораторна робота №9. Форма зворотного зв'язку

- Семантична адаптивна форма `#feedbackForm` (Tailwind CSS): `label`/`for`, `aria-describedby`, `aria-invalid`.
- Клієнтська валідація (`js/validation.js`): ім'я, email, телефон `+380XXXXXXXXX` (RegEx), повідомлення, згода.
- Перевірка під час `blur`, `input` і `submit`; червоні та зелені стани полів.
- Модальне вікно успіху: закриття через Esc, клік по оверлею й кнопку, повернення фокусу.
- Додаткові сторінки: `privacy.html`, `offer.html`.
- Реального надсилання даних на сервер немає, це демонстрація клієнтської валідації.
